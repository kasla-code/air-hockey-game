# air-hockey-game
Air Hockey Game

## Contributing

This project uses [uv](https://docs.astral.sh/uv/) as both a package and project manager. For help installing uv, contributors will find the following [installation documentation](https://docs.astral.sh/uv/getting-started/installation/) useful.

To setup your environment, install uv, clone the repo locally, and run `uv sync` in the command line.

### Pre-commit Checks

This project adheres to set linting, formatting, and code quality standards. Before committing any code, contributors are encouraged to run `uv run poe check` in the command line to see if written code follows these standards.
